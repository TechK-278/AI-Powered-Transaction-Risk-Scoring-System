When asked to review code:

Do not rewrite everything immediately.

First:

1. Find bugs.

2. Find security issues.

3. Find performance issues.

4. Find architecture issues.

5. Find maintainability issues.

6. Find AI-generated code patterns.

7. Suggest improvements.

Only rewrite code after explaining why changes are needed.

Review code like a senior software engineer conducting a pull request.

Be strict.

Do not approve mediocre code.
